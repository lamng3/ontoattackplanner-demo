Playground

Attack a small ontology in your browser: edit it, let the library's search find the worst chain of edits, see which action did the damage, and roll back to the last healthy state.

What runs where

Everything runs in your browser. Aegis itself is Python and is not run here: the page runs a JavaScript port of the small materials example (examples/attack_and_recover.py): the ontology and its four edit primitives, the workload's F1 and harm, per-action attribution, the versioned log with rollback and last-healthy, and the library's greedy and beam attack searches. Its tests recompute the impacts, the candidate edits, the searches at four budgets, and 40 random edit chains against the Python and compare every number. The real ontologies, UCT search, protection by locking, and the memory defenses are not run here.
